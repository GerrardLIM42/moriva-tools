* 업로드한 이미지·동영상은 서버로 전송되지 않고 브라우저 안에서만 미리보기로 사용됩니다.
* 실제 쿠팡 화면과 100% 동일하지 않은 목업(mock-up) 화면입니다.
* "실행" 버튼을 누르면 좌측 패널 없이 화면 전체로 상품페이지를 확인할 수 있어요.
* 동영상은 용량이 크면 브라우저가 느려질 수 있으니 너무 긴 파일은 피해주세요.
* HTML 블록은 독립된 영역(iframe)에 렌더링되어 안의 스크립트도 실제로 동작하며, 주변 화면 스타일에는 영향을 주지 않아요.
* "링크/QR로 폰에서 보기"는 GitHub 동기화가 연결되어 있으면 이미지·동영상도 함께 전달돼요. 용량이 크면 이미지는 자동으로 화질을 낮춰 전송하고, 그래도 너무 크면 동영상은 제외될 수 있어요. 연결되어 있지 않으면 텍스트 정보만 전달돼요.
